## 1. 정한 것

| # | 결정 | 이유 |
|---|---|---|
| D1 | **끝나면 `lib/` 어디에도 `package:flutter/material.dart` · `cupertino.dart` import 가 없다.** 앱은 `WidgetsApp.router` 위에 선다 | 「테마로 덮기」는 8-22 에 해 봤고 부족했다. 뼈대까지 걷지 않으면 Material 의 동작(물결 · 오버스크롤 글로 · 페이지 전환 · 선택 핸들)이 새어 나온다 |
| D2 | **정적 검사로 막는다** — `test/no_platform_ui_test.dart` 가 `lib/` 를 훑어 두 import 를 찾는다. 이관 중에는 **줄어들기만 하는 허용 목록**을 두고, 목록 밖 파일이 import 하면 실패, 목록 안 파일이 더는 import 하지 않는데 목록에 남아 있어도 실패 | 규칙이 말로만 있으면 다음 화면에서 다시 들어온다. 허용 목록이 스스로 줄어드는지 검사해야 이관이 끝난 파일이 되돌아가지 않는다 |
| D3 | 자체 컴포넌트는 **`lib/ui/`** 한 곳. 이름은 `Nx` 접두사(`NxButton` · `NxField` …). `widgets.dart` · `services.dart` · `rendering.dart` 만 쓴다 | 캔버스의 「컴포넌트 세트」와 1:1. 화면 코드는 `ui/` 만 본다 |
| D4 | **테마는 `NxTheme`(InheritedWidget)** 이 토큰을 밝기에 맞춰 풀어 준다 — `NxTheme.of(context).colors.bgSurface` · `.text.body`. 토큰 이름은 그대로(`tokens.css` ↔ Dart 1:1) | `Theme.of` 104곳의 자리. `ThemeData` 는 Material 이라 쓸 수 없다. 이름을 바꾸면 디자인 문서와 대조할 수 없다(CLAUDE.md 앱 규칙) |
| D5 | **아이콘은 자체 `NxIcon`** — 캔버스의 선 아이콘을 `CustomPainter` 경로로 옮긴다(약 25개). 굵기 1.5 · 16 격자 | `Icons.*` 는 Material 아이콘 글꼴이다. 패키지(SVG)를 들이지 않는다(§3-8). 아이콘은 **글자 없는 아이콘 버튼과 상태 표시에만** 쓴다 — 목록 행 앞 장식 아이콘은 없앤다(사용자 지시) |
| D6 | **텍스트 입력은 `EditableText` 위에 직접** — 선택 제스처는 `TextSelectionGestureDetectorBuilder`(widgets), 핸들과 우클릭 메뉴는 자체(`NxTextSelectionControls` · `NxMenu`) | `TextField` 는 Material 이다. Cupertino 의 `CupertinoTextField` 가 정확히 이 구조로 만들어져 있어 길이 검증돼 있다. 멘션 입력창의 커스텀 컨트롤러는 그대로 붙는다 |
| D7 | **누르는 피드백은 물결이 아니라 배경 한 단** — `NxPressable`(hover · pressed · focus 링 2px + 2px 오프셋) | 디자인 시스템 §4(모션 120ms · 그림자 없음) · §6(포커스 링) |
| D8 | 오버레이는 **`OverlayPortal`** 로 — 메뉴 · 툴팁 · 동작 카드 · 셀렉트. 다이얼로그는 `showGeneralDialog`(widgets) 위의 `NxDialog` | 둘 다 widgets 층이다. 바텀시트는 만들지 않는다 — 모바일 길게 누르기는 **누른 메시지 곁의 동작 카드**(캔버스) |
| D9 | **알림은 `NxToast`** — 앱 맨 위 `NxToastHost` 가 줄을 세워 하나씩 띄운다 | SnackBar 28곳의 자리. `ScaffoldMessenger` 없이 어디서나 `NxToast.show(context, …)` |
| D10 | **로딩은 뼈대 줄(`NxSkeleton`)** , 버튼 안에서만 작은 호(`NxSpinner`) | 회전 스피너 26곳이 화면을 흔든다. 자리를 지키는 뼈대가 캔버스 결정이다 |
| D11 | **화면 틀은 `NxPage`(머리 줄 + 본문)** — AppBar · Scaffold 의 자리. 키보드는 `MediaQuery.viewInsets` 로 직접 비킨다 | 셸 밖 화면(스레드 · 저장소 · PR · 설정) 17곳이 AppBar 를 쓴다 |
| D12 | **모바일 탭은 글자 탭 + 위 막대(`NxTabBar`)**, 머리는 **채널 이름 버튼**(햄버거 없음), 채널 목록은 왼쪽에서 밀려 나오는 자체 패널 | 캔버스 결정. Material NavigationBar · Drawer 의 자리 |
| D13 | **스크롤은 `NxScrollBehavior`** — 안드로이드 오버스크롤 글로를 끄고 데스크톱은 얇은 자체 스크롤바(`RawScrollbar`) | `WidgetsApp` 의 기본 `ScrollBehavior` 도 안드로이드에서 글로를 그린다 — 빼먹기 쉬운 기본 UI |
| D14 | **페이지 전환은 자체** — 셸 밖으로 덮어 여는 화면만 180ms 페이드 + 8px 올라옴, 셸 안은 전환 없음 | `WidgetsApp` 에서 go_router 는 `NoTransitionPage` 를 쓴다. 덮는 화면에만 `pageBuilder` 로 전환을 준다 |
| D15 | **이슈 보드 드래그 정렬 화면**을 이 단계에 만든다 — 끌면 카드가 한 단 밝은 표면 + 액센트 테두리, 놓일 자리는 점선. 키보드(Space 로 집고 방향키)로도 옮긴다 | 로드맵(09-27) 결정. 서버 `PUT .../position` 은 9-1 부터 있다 |

## 3. 15-2 — 화면 이관

영역마다 한 커밋 이상, 끝나면 그 파일들을 허용 목록에서 뺀다. 순서는 **덜 쓰는 곳 → 많이 쓰는 곳**
(컴포넌트의 빈 곳을 작은 화면에서 먼저 드러낸다):

1. 로그인 · 스페이스 고르기 · 설정 창
2. 셸(레일 · 채널 패널 · 모바일 탭 · 채널 패널 밀어내기)
3. 파일 · 저장소 목록 · 저장소 열람 · 커밋 · PR
4. 이슈 보드(드래그 정렬 포함) · 상세 · 스프린트
5. 채팅 · 스레드 · AI 패널(가장 크다 — 입력창 · 멘션 · 동작 카드 · 선택 모드)
6. 공용(`shared/markdown` · 아바타 · 로고)

**위젯 · 통합 테스트는 이관과 함께 고친다** — Material 타입으로 찾는 곳(`find.byType(FilledButton)`
등)은 `Nx` 타입이나 글자로 바꾼다. `app:flow` 는 영역마다 돌린다.

## 4. 15-3 — 뼈대

- `MaterialApp.router` → `WidgetsApp.router` + `NxTheme` + `NxToastHost` + `NxScrollBehavior`
- `core/theme.dart` 의 `ThemeData` 조립 삭제(토큰 상수는 `ui/theme.dart` 로)
- 허용 목록이 빈다 — `no_platform_ui_test` 는 이제 예외 없이 막는다
- **Android · 웹 확인**(슬라이스 경계): 소프트 키보드 · 선택 핸들 · 뒤로 가기 · 오버스크롤

## 6. 위험

- **텍스트 입력이 가장 크다.** IME 조합 · 선택 · 붙여넣기 · 한글 · 멘션 커서를 `EditableText` 위에서
  다시 확인해야 한다. 15-1 에서 `NxField` 를 먼저 만들고 **Windows 에서 한글 입력을 눈으로** 본다
- 접근성 — Material 이 공짜로 주던 Semantics 를 직접 달아야 한다. 컴포넌트 테스트가 Semantics 를 단언한다
- 테스트 대량 수정 — 이관 커밋마다 `flutter test` · `app:flow` 를 돌려 한꺼번에 무너지지 않게 한다
