# 14 사용자 설정 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 디스코드식 설정 창 하나로 표시 이름 · 프로필 사진 · 비밀번호 · 채널 음소거 · 테마를 바꾼다.

**Architecture:** 서버는 `users` 모듈에 아바타(저장 · 가공 · 열람)를, `auth` 에 비밀번호 변경을, `channels` 에 음소거를 더한다. 바뀐 이름 · 사진은 `user:updated` 로 스페이스 룸에 퍼지고, 앱은 그것을 drift 에 반영한다. 앱의 설정 창은 셸 밖 `/settings/:section` 이고 폭 분기는 `app_shell.dart` 의 `SettingsFrame` 한 곳이다.

**Tech Stack:** NestJS · Prisma · sharp · argon2 · Socket.IO / Flutter · Riverpod 3 · go_router · drift · file_picker

**Spec:** `docs/superpowers/specs/2026-09-27-14-사용자-설정-design.md`

## Global Constraints

- 코드 주석 · 문서 · 커밋 메시지는 한국어. 커밋 제목은 명사로 끝낸다(`… 추가` · `… 수정`). 본문은 개조식 문어체. `Co-Authored-By` 를 넣지 않는다
- 볼 수 없으면 404(403 아님). 아바타 열람 · 음소거 모두
- 입력은 class-validator DTO. 전역 파이프가 DTO 밖 필드를 400 으로 거부한다
- raw SQL 에 `now()` 금지 · id 에 `::uuid` 캐스팅 금지
- 마이그레이션은 `nexus-migration` 스킬 절차(손으로 쓴 SQL, HNSW DROP 이 섞이지 않게)
- 앱: 화면은 drift 만 구독 · 서버 문구를 화면에 쓰지 않음 · 폭 분기는 `app_shell.dart` 한 곳 · 패키지를 새로 들이지 않음
- drift 캐시 테이블을 바꾸면 `schemaVersion` 을 올린다(16 → 17). 전송 큐 스키마는 건드리지 않는다
- 모델을 고치면 `dart run build_runner build`, 생성물은 커밋한다
- 아바타: 입력 PNG · JPEG · WebP · GIF, 5MB 이하, 출력 256×256 WebP, 키 `avatars/<userId>/<uuid>.webp`, 주소 `/users/<id>/avatar?v=<uuid 앞 8자>`
- 비밀번호: 10~128자, 틀린 현재 비밀번호 400

### Task 1: 아바타 가공 함수

**Files:** Create `server/src/users/avatar-image.ts`, Test `server/src/users/avatar-image.spec.ts`

**Interfaces:** Produces `processAvatar(input: Buffer): Promise<Buffer>` — 256×256 WebP. 이미지가 아니면 `AvatarImageError` 를 던진다. `AVATAR_EDGE`, `MAX_AVATAR_BYTES`, `AVATAR_MIME = 'image/webp'`.

- [ ] Step 1: 테스트 — sharp 로 만든 입력(가로 400×200 PNG · 투명 PNG · 1×1 JPEG · GIF)을 넣어 결과 metadata 가 `webp` · 256×256 인지, 가로로 긴 사진이 늘어나지 않고 가운데가 잘리는지(왼쪽 절반 빨강 · 오른쪽 절반 파랑 → 결과 가운데 픽셀이 두 색 경계), 텍스트 버퍼는 `AvatarImageError` 인지
- [ ] Step 2: `npx jest src/users/avatar-image.spec.ts` 실패 확인
- [ ] Step 3: 구현

```ts
export async function processAvatar(input: Buffer): Promise<Buffer> {
  try {
    return await sharp(input, { animated: false })
      .rotate()
      .resize(AVATAR_EDGE, AVATAR_EDGE, { fit: 'cover', position: 'centre' })
      .webp({ quality: 85 })
      .toBuffer();
  } catch {
    throw new AvatarImageError();
  }
}
```
