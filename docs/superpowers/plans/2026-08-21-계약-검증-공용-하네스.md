# 계약 검증 공용 하네스 — 구현 계획

> **에이전트 작업자에게:** 이 계획은 `superpowers:subagent-driven-development`
> 또는 `superpowers:executing-plans` 로 task 단위로 실행한다. 단계는 체크박스
> (`- [ ]`)로 추적한다.

**Goal:** 계약 검증 스크립트 11종에 11벌씩 복사된 헬퍼를 `lib/` 모듈 셋으로 모은다.

**Architecture:** `server/scripts/lib/` 에 `api.mjs`(HTTP · 가입) ·
`checks.mjs`(집계 · 표시) · `socket.mjs`(소켓)를 두고, 이미 있는
`preflight.mjs` 옆에 나란히 둔다. 각 스크립트는 **필요한 것만** import 한다.
**검증의 내용은 한 줄도 고치지 않는다** — 모양만 바꾼다.

**Tech Stack:** 순수 ESM(`.mjs`) · Node 22 · 프레임워크 없음

**설계 문서:** [2026-08-21-계약-검증-공용-하네스-design.md](../specs/2026-08-21-계약-검증-공용-하네스-design.md)

## Global Constraints

- **주석 · 커밋 메시지 · 문서는 전부 한국어.** 커밋에
  `Co-Authored-By: Claude` 를 넣지 않는다
- **케이스와 단언 내용을 고치지 않는다.** 이 조각은 검증의 내용이 아니라
  모양을 바꾼다. 케이스 수가 바뀌면 그것이 곧 결함이다
- **회귀 관문 — 케이스 수가 아래와 정확히 같아야 한다**

  | 스크립트 | 수 | | 스크립트 | 수 |
  |---|---:|---|---|---:|
  | `issues` | 89 | | `pins` | 20 |
  | `oauth` | 76 | | `mentions` | 18 |
  | `browse` | 56 | | `quotes` | 17 |
  | `attachments` | 43 | | `repos` | 30 |
  | `threads` | 25 | | `reactions` | 24 |

  `realtime` 41 은 **이 PC 에서 못 돈다**(시드 비밀번호를 알 수 없다) — CI 로 확인
- **표시는 `OK` / `FAIL`,** 집계 줄은 **`통과 N · 실패 N`** 으로 통일한다
- **`check-migrations.mjs` 는 대상이 아니다.** DB 도 서버도 없이 도는 정적 검사다
- **`check-browse.mjs` 의 `connect()` 를 `lib/socket.mjs` 로 접지 않는다.**
  이름만 같고 GitHub 계정을 연결하는 다른 함수다 — `connectGithub()` 으로
  이름만 바꾼다
- **`check-mentions.mjs` 는 계정 이름을 단언에 쓴다.** 이름을 기계적으로
  바꾸면 케이스가 깨진다 — 자기 이름을 명시적으로 넘긴다
- **`process.exit()` 는 열린 핸들이 있을 때 쓰지 않는다.** Windows libuv 의
  `UV_HANDLE_CLOSING`. 각 스크립트의 꼬리 정리 순서를 건드리지 않는다

**Interfaces:**

- [ ] **Step 1: `lib/api.mjs` 를 만든다**

```js
// 계약 검증 스크립트의 공용 HTTP 헬퍼.
//
// **주소를 아는 곳은 여기 하나다.** 이전에는 11벌이 각자 BASE 를 선언해,
// 주소가 바뀌면 열한 곳을 고쳐야 했다. 앱의 core/env.dart 와 같은 규칙이다.

export const BASE = 'http://127.0.0.1:3000/api';

// 한 프로세스 안에서 값이 하나여야 한다는 뜻을 모듈로 표현한다.
// base36 은 짧아서 스페이스 이름·이메일에 끼워 넣기 좋다. 이전에는 이 형태와
// Date.now() 가 섞여 있었다.
export const stamp = Date.now().toString(36);

export async function api(method, path, { token, body } = {}) {
  const res = await fetch(BASE + path, {
    method,
    headers: {
      'content-type': 'application/json',
      ...(token ? { authorization: `Bearer ${token}` } : {}),
    },
    ...(body ? { body: JSON.stringify(body) } : {}),
  });
  let json = null;
  try {
    json = await res.json();
  } catch {
    /* 본문 없음 */
  }
  return { status: res.status, json };
}

// 검증용 계정을 만든다. 비밀번호는 어디서도 재사용되지 않으므로(로그인하는
// 스크립트는 check-realtime 하나뿐이고 그것은 시드 계정을 쓴다) 상수로 둔다.
const PASSWORD = 'check-harness-1234';

/**
 * @param prefix 이메일 접두사. 스크립트마다 다르게 주어 계정이 섞이지 않게 한다
 * @param tag    같은 스크립트 안에서 계정을 가르는 꼬리표
 * @param name   표시 이름. **check-mentions 는 이 값을 단언에 쓰므로**
 *               반드시 자기 이름을 명시적으로 넘긴다
 */
export async function signup(prefix, tag, name = `${prefix}검증${tag}`) {
  const res = await api('POST', '/auth/signup', {
    body: {
      email: `${prefix}-${tag}-${stamp}@example.com`,
      password: PASSWORD,
      name,
      client: 'native',
    },
  });
  if (res.status !== 201) {
    console.error('가입 실패:', res.status, JSON.stringify(res.json));
    process.exit(1);
  }
  return { token: res.json.accessToken, userId: res.json.user.id };
}
```

- [ ] **Step 2: `lib/checks.mjs` 를 만든다**

```js
// 계약 검증의 통과/실패 집계와 표시.
//
// **모듈 수준 상태로 충분하다.** 각 스크립트가 자기 프로세스라 모듈이
// 프로세스마다 새로 로드되고, 격리가 공짜다. 팩토리를 만들 이유가 없다.

let pass = 0;
let fail = 0;

export function check(name, ok, detail = '') {
  if (ok) {
    pass++;
    console.log(`  OK  ${name}`);
  } else {
    fail++;
    console.log(`FAIL  ${name} ${detail}`);
  }
}

export function counts() {
  return { pass, fail };
}

/**
 * 집계를 찍고 종료 코드를 세팅한다. **정리에는 관여하지 않는다** —
 * 가짜 서버를 닫고 소켓을 끊는 순서는 스크립트마다 다르고, Windows libuv 의
 * UV_HANDLE_CLOSING 때문에 조심스럽게 짜여 있다.
 *
 * @returns 실패 수
 */
export function summary() {
  console.log(`\n통과 ${pass} · 실패 ${fail}\n`);
  if (fail > 0) process.exitCode = 1;
  return fail;
}
```

- [ ] **Step 3: `lib/socket.mjs` 를 만든다**

```js
// 계약 검증의 공용 소켓 헬퍼.
//
// **socket.io-client 를 import 하는 곳은 여기 하나다.** 소켓을 쓰지 않는
// 스크립트(attachments · mentions · oauth · repos · browse)가 그것을 로드하지
// 않도록 파일을 갈랐다.
import { io } from 'socket.io-client';

export const WS = 'http://127.0.0.1:3000';

/**
 * 연결되면 소켓을, 거부되면 오류를 돌려준다(던지지 않는다) — 거부되는 것
 * 자체가 검증 대상이기 때문이다.
 *
 * token 이 undefined 면 auth 를 통째로 비운다. `{ token: undefined }` 를
 * 보내는 것과 다르고, "토큰 없이 연결하면 거부"를 시험하려면 이쪽이어야 한다.
 */
export function connect(token) {
  return new Promise((resolve) => {
    const socket = io(WS, {
      auth: token === undefined ? {} : { token },
      transports: ['websocket'],
      reconnection: false,
      timeout: 5000,
    });
    socket.once('connect', () => resolve(socket));
    socket.once('connect_error', (err) => resolve(err));
  });
}

/** 이벤트를 기다린다. 시간 안에 안 오면 null — 그것도 검증 대상이다. */
export function waitFor(socket, event, ms = 3000) {
  return new Promise((resolve) => {
    const timer = setTimeout(() => {
      socket.off(event, handler);
      resolve(null);
    }, ms);
    const handler = (payload) => {
      clearTimeout(timer);
      resolve(payload);
    };
    socket.once(event, handler);
  });
}
```

- [ ] **Step 2: 다섯 파일에서 지역 헬퍼와 상수를 지우고 import 로 바꾼다**

각 파일에서 **지운다**:

- `const BASE = 'http://127.0.0.1:3000/api';`
- `const stamp = Date.now();` 또는 `const stamp = Date.now().toString(36);`
- `let pass = 0;` · `let fail = 0;`
- `function check(...) { … }` 전체
- `async function api(...) { … }` 전체
- `async function signup(tag) { … }` 전체

각 파일 맨 위에 **넣는다**(기존 `preflight` import 옆):

```js
import { BASE, stamp, api, signup } from './lib/api.mjs';
import { check, summary } from './lib/checks.mjs';
```

**꼬리는 파일마다 다르다. 아래 표대로 정확히 바꾼다.**

`summary()` 를 그냥 끼우면 안 되는 파일이 있다 — **`process.exit()` 로 끝내던
것들은 그것이 필요해서 그렇게 쓴 것이다.** 소켓이나 열린 핸들이 남아 있으면
이벤트 루프가 비지 않아 **스크립트가 끝나지 않는다.** `summary()` 가 실패 수를
돌려주므로 그 값으로 같은 종료를 만든다.

| 파일 | 바꾸기 전 | 바꾼 뒤 |
|---|---|---|
| `attachments` · `mentions` · `repos` | `console.log(\`\n통과 ${pass} · 실패 ${fail}\n\`);`<br>`process.exit(fail === 0 ? 0 : 1);` | `process.exit(summary() === 0 ? 0 : 1);` |
| `browse` | `console.log(…);`<br>`if (fail > 0) process.exitCode = 1;` | `summary();` |
| `oauth` | `console.log(…);`<br>`await new Promise((resolve) => fake.close(() => resolve()));`<br>`process.exitCode = crashed \|\| fail > 0 ? 1 : 0;` | `summary();`<br>`await new Promise((resolve) => fake.close(() => resolve()));`<br>`if (crashed) process.exitCode = 1;` |

`oauth` 에서 **집계를 찍는 자리와 `fake.close()` 의 순서를 바꾸지 않는다.**
그리고 `? 1 : 0` 의 `0` 을 버려도 되는 이유는 `process.exitCode` 의 기본값이
0 이기 때문이다 — 원래도 실패가 없으면 0 이었다.

**`signup` 호출을 접두사와 함께 바꾼다** — 지금은 `signup(tag)` 다.

| 파일 | 바꾸기 전 | 바꾼 뒤 |
|---|---|---|
| `check-attachments.mjs` | `signup('a')` | `signup('att', 'a')` |
| `check-mentions.mjs` | `signup('a')` | `signup('mention', 'a', \`멘션검증a\`)` |
| `check-oauth.mjs` | `signup('a')` | `signup('oauth', 'a')` |
| `check-repos.mjs` | `signup('a')` | `signup('repo', 'a')` |
| `check-browse.mjs` | `signup('a')` | `signup('browse', 'a')` |

`'a'` 외의 꼬리표(`'b'` · `'x'` 등)도 같은 방식으로 바꾼다.

- `import { io } from 'socket.io-client';`

| 파일 | 접두사 |
|---|---|

| `check-pins.mjs` | `pin` |
| `check-quotes.mjs` | `quote` |
| `check-reactions.mjs` | `reaction` |
| `check-threads.mjs` | `thread` |

**꼬리는 아래 표대로 바꾼다.** 다섯이 `process.exit()` 로 끝나는데, 소켓이
열려 있어 이벤트 루프가 비지 않기 때문이다 — 그냥 `summary()` 로 바꾸면
**스크립트가 끝나지 않는다.**

| 파일 | 바꾸기 전 | 바꾼 뒤 |
|---|---|---|
| `issues` · `pins` · `quotes` · `reactions` · `threads` | `console.log(\`\n통과 ${pass} · 실패 ${fail}\n\`);`<br>`process.exit(fail === 0 ? 0 : 1);` | `process.exit(summary() === 0 ? 0 : 1);` |
| `realtime` | Step 3 참고 | Step 3 참고 |

- [ ] **Step 3: `check-realtime.mjs` 의 집계 함수를 고친다**

이 스크립트만 집계가 `report()` 안에 있고 구분자가 `/` 다. 정리(소켓 끊기)는
**그대로 두고** 집계만 `summary()` 로 넘긴다.

바꾸기 전:

```js
function report() {
  for (const s of sockets) s.disconnect();
  console.log(`\n통과 ${pass} / 실패 ${fail}`);
  process.exitCode = fail ? 1 : 0;
}
```

바꾼 뒤:

```js
function report() {
  for (const s of sockets) s.disconnect();
  summary();
}
```

**`process.exitCode = fail ? 1 : 0` 이 `summary()` 안의
`if (fail > 0) process.exitCode = 1` 로 바뀐다.** 실패가 없을 때 0 을 명시적으로
넣지 않는 차이인데, 기본값이 0 이라 동작이 같다.
