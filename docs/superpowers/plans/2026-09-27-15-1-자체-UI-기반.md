# 15-1 자체 UI 기반 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Material · Cupertino 없이 `widgets.dart` 만으로 만든 컴포넌트 세트(`lib/ui/`)와, Material import 가 늘지 않게 막는 정적 검사를 만든다. 화면은 건드리지 않는다.

**Architecture:** `NxTheme`(InheritedWidget)이 토큰을 밝기별로 풀고, 컴포넌트는 모두 `NxPressable`(포커스 · 호버 · 눌림 · 키보드 · Semantics) 위에 선다. 텍스트 입력은 `EditableText` + `TextSelectionGestureDetectorBuilder`. 오버레이는 `OverlayPortal`, 다이얼로그는 `showGeneralDialog`, 알림은 자체 `NxToastHost`.

**Tech Stack:** Flutter widgets 층(`widgets.dart` · `services.dart` · `rendering.dart` · `gestures.dart`) · flutter_test

**Spec:** `docs/superpowers/specs/2026-09-27-15-자체-UI-design.md`

## Global Constraints

- `lib/ui/**` 는 `package:flutter/material.dart` · `cupertino.dart` 를 import 하지 않는다(D1 · D3)
- 새 패키지를 들이지 않는다(CLAUDE.md §3-8)
- 토큰 이름 · 값은 `design-system/tokens.css` 와 1:1(D4). 반경 sm 4 · md 8 · full 9999, 모션 micro 120ms · panel 180ms
- 그림자를 쓰지 않는다. 포커스 링은 액센트 2px + 2px 오프셋. 모바일 터치 타깃 44px
- 목록 행 앞 장식 아이콘을 두지 않는다. 아이콘은 글자 없는 버튼 · 상태 표시에만(D5)
- 커밋: 한국어, 제목은 명사로 끝냄, 본문 개조식. `Co-Authored-By` 없음
- CI Flutter 는 3.44.9 — 그보다 새 API 를 쓰지 않는다
