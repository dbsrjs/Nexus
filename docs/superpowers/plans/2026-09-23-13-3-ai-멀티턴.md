# 13-3 AI 멀티턴 구현 계획

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** AI 패널의 답 아래에서 이어 물을 수 있게 한다 — `POST /ai/ask` 에 `parentRunId` 를 더하고, 사슬의 첫 문답 근거를 물려받아 user · assistant 역할을 나눈 멀티턴으로 LLM 에 보낸다.

**Architecture:** `ai_runs.parent_run_id` 로 문답을 사슬로 잇는다. 적재 때와 워커 실행 때 같은 순수 함수 `buildFollowUpPrompt()` 가 `[첫 문답 … 부모] + 새 질문` 을 메시지로 만든다(첫 문답의 자료는 첫 user 에만). 캐시는 `promptHash` 그대로이고, 앱 패널은 문답 목록을 상태로 든다.

**Tech Stack:** NestJS 10 · Prisma 5 · PostgreSQL · Flutter(Riverpod · freezed)

**Spec:** `docs/superpowers/specs/2026-09-23-13-3-ai-멀티턴-design.md`

## Global Constraints

- 브랜치 `feat/13-3-multiturn`. 커밋 메시지는 한국어 개조식, 제목은 명사로 끝낸다(`… 추가` · `… 수정`). `Co-Authored-By` 넣지 않는다
- 사슬 상한 **10 문답**(첫 문답 + 후속 9). 서버 `MAX_THREAD_TURNS = 10`, 앱도 같은 값
- 후속 질문 지시문 상한은 13-2 그대로 **2000자**
- 볼 수 없으면 403 이 아니라 **404**. 부모는 같은 스페이스 · 같은 사용자만
- 마이그레이션은 `nexus-migration` 스킬 절차(diff → HNSW `DROP INDEX` 제거 → deploy → generate)
- raw SQL 을 새로 쓰지 않는다
- 모델(freezed)을 고치면 `dart run build_runner build --delete-conflicting-outputs`, 생성물 커밋. `app/pubspec.lock` 이 SDK 차이로 바뀌면 `git restore`

```ts
import { AiRunKind } from '@prisma/client';
import { LlmMessage } from '../../llm/llm.provider';
import { AskRequest } from '../ask-request';
import { ASK_SYSTEM } from './ask';
import { AskMaterial, BuiltPrompt, buildAskPrompt } from './build';

/** 사슬 상한 — 첫 문답 + 후속 9 (13-3 설계 D5). 앱도 같은 값이다. */
export const MAX_THREAD_TURNS = 10;

export interface ThreadTurn {
  question: string;
  answer: string;
}

/** 사슬. 첫 문답은 자료를 들고, 뒤 문답은 지시문과 답만 든다. */
export interface FollowUpThread {
  root: Pick<AskRequest, 'instruction' | 'preset'>;
  rootAnswer: string;
  /** 첫 문답 뒤의 문답들 — 오래된 것부터. */
  later: ThreadTurn[];
}

/**
 * 이어 묻기 프롬프트 (13-3 설계 §3). **순수 함수다** — 적재(해시)와 워커가
 * 같은 것을 부른다.
 *
 * 첫 user 는 13-2 의 `buildAskPrompt` 가 만든 그대로다(자료 + 첫 요청). system 은
 * **언제나 ask 의 것** — 요약 system 은 세 항목 양식을 강제해 후속 답까지 굳힌다.
 */
export function buildFollowUpPrompt(
  thread: FollowUpThread,
  material: AskMaterial,
  instruction: string,
): BuiltPrompt {
  if (thread.root.preset === 'issue') {
    throw new Error('이슈 초안에는 이어 묻지 않습니다.');
  }
  const first = buildAskPrompt(thread.root, material);
  const firstUser = first.messages.find((m) => m.role === 'user');
  if (!firstUser) throw new Error('첫 문답에 user 가 없습니다.');

  const messages: LlmMessage[] = [
    { role: 'system', content: ASK_SYSTEM },
    firstUser,
    { role: 'assistant', content: thread.rootAnswer },
  ];
  for (const turn of thread.later) {
    messages.push({ role: 'user', content: turn.question });
    messages.push({ role: 'assistant', content: turn.answer });
  }
  messages.push({ role: 'user', content: instruction });
  return { kind: AiRunKind.ask, messages, json: false };
}
```
