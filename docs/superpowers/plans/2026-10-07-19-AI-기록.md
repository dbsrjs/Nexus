# 19 AI 기록 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** AI 패널에서 지난 문답 사슬을 목록으로 보고, 다시 열어 이어 묻는다.

**Architecture:** 서버는 스키마를 바꾸지 않고 `parent_run_id` 를 재귀 CTE 로 따라 내려가 사슬의 끝(가장 늦게 끝난 `done`)을 찾는다. `GET .../ai/threads`(목록) · `GET .../ai/threads/:rootRunId`(사슬) 두 경로를 `AiHistoryService` 가 맡는다. 앱은 AI 패널에 「지난 대화」 모드를 더하고, 다시 연 사슬은 13-3 의 문답 화면을 그대로 탄다.

**Tech Stack:** NestJS · Prisma `$queryRaw` · Postgres 재귀 CTE · Flutter(Riverpod 3 · freezed) · 자체 UI(`ui/`)

**Spec:** [docs/superpowers/specs/2026-10-07-19-AI-기록-design.md](../specs/2026-10-07-19-AI-기록-design.md)

## Global Constraints

- 코드 주석 · 문서 한국어. 커밋 제목은 명사로 끝냄(`… 추가` · `… 수정`), 본문 개조식 문어체, **`Co-Authored-By` 넣지 않음**
- 본인 것만(`userId` 를 모든 WHERE 에) · 스페이스 격리(`spaceId` 를 모든 WHERE 에) · 볼 수 없으면 404
- 채널 가시성 판정은 `ChannelsService.viewableChannelIds(member)` 만 — Prisma `where` 로 다시 쓰지 않음
- raw SQL: `now()` 금지 · id 를 `::uuid` 로 캐스팅 금지(컬럼은 `text`)
- 사슬 상한 `MAX_THREAD_TURNS = 10`(server `prompts/follow-up.ts`) · 앱 `maxThreadTurns = 10`
- 페이지: `PaginationDto`(`cursor` 문자열 · `limit` 1~100). 이 경로의 기본 `limit` 은 20
- 앱: material · cupertino import 금지, 색 · 글자 · 간격은 `NxTheme` 토큰만(`design_tokens_test` 가 잡음), 서버 오류 문구를 화면에 쓰지 않음
- 서버 코드를 고친 뒤 계약 검증 전에 3000번 프로세스 시작 시각이 고친 시각보다 뒤인지 확인(CLAUDE.md §2)

```ts
import { AiRunKind, Prisma } from '@prisma/client';
import { AskPreset } from './ask-request';
import type { StoredAskInput } from './ai.service';

/** 목록 미리보기 길이. 원문(마크다운)을 자르고 평문화는 앱이 한다(19 설계 D9). */
export const PREVIEW_MAX = 200;

/** 13-1 에서 적재된 행은 `{channelId, messageIds}` 뿐이다 — 요약으로 읽는다. */
export function rootRequestOf(input: StoredAskInput): {
  instruction: string | null;
  preset: AskPreset | null;
} {
  return {
    instruction: input.instruction ?? null,
    preset: input.preset ?? (input.instruction === undefined ? 'summary' : null),
  };
}

/** 목록 · 사슬에서 뿌리 질문을 보이는 모양. */
export function rootQuestionOf(input: StoredAskInput) {
  const { instruction, preset } = rootRequestOf(input);
  return { question: instruction, preset };
}

export function previewOf(kind: AiRunKind, result: Prisma.JsonValue): string {
  const r = (result ?? {}) as { markdown?: unknown; title?: unknown };
  const text = kind === AiRunKind.draft_issue ? r.title : r.markdown;
  return typeof text === 'string' ? text.slice(0, PREVIEW_MAX) : '';
}

export function listContextOf(input: StoredAskInput) {
  return {
    channelId: input.channelId ?? null,
    messageCount: input.messageIds?.length ?? null,
    repoId: input.repoId ?? null,
  };
}

export function threadContextOf(input: StoredAskInput) {
  return {
    channelId: input.channelId ?? null,
    messageIds: input.messageIds ?? null,
    repoId: input.repoId ?? null,
  };
}
```

```ts
/**
 * 실행 하나를 앱에 보이는 모양. `GET .../ai/runs/:runId` 와 사슬 읽기(19)가 같은 것을

export const RUN_VIEW_SELECT = {
  id: true,
  kind: true,
  state: true,
  result: true,
  error: true,
  model: true,
  fallback: true,
  parentRunId: true,
  promptTokens: true,
  completionTokens: true,
  createdAt: true,
  finishedAt: true,
} satisfies Prisma.AiRunSelect;

export type RunViewRow = Prisma.AiRunGetPayload<{ select: typeof RUN_VIEW_SELECT }>;

export function toRunView(row: RunViewRow) {
  const { id, ...rest } = row;
  return { runId: id, ...rest };
}
```

```js
// ── 19 AI 기록 ───────────────────────────────────
console.log('\n[19 AI 기록]');
{
  const dave = await signup('ai', 'h', 'AI검증h');
  const erin = await signup('ai', 'i', 'AI검증i');
  const hs = (await api('POST', '/spaces', { token: dave.token, body: { name: `ai hist ${stamp}` } })).json;
  const hInvite = await api('POST', `/spaces/${hs.id}/invites`, { token: dave.token, body: {} });
  await api('POST', `/invites/${hInvite.json.code}/accept`, { token: erin.token });
  const hChannel = (await api('GET', `/spaces/${hs.id}/channels`, { token: dave.token })).json[0];
  const hMsg = (await api('POST', `/spaces/${hs.id}/channels/${hChannel.id}/messages`, {
    token: dave.token, body: { body: '기록 검증용 대화' },
  })).json;

  const threads = (token, q = '') => api('GET', `/spaces/${hs.id}/ai/threads${q}`, { token });
  const thread = (token, id, sid = hs.id) => api('GET', `/spaces/${sid}/ai/threads/${id}`, { token });
  const hAsk = (token, body) => api('POST', `/spaces/${hs.id}/ai/ask`, { token, body });
  const hDone = async (token, started) => {
    const id = started.json?.runId;
    if (started.json?.state === 'queued') await waitForRunDone(token, hs.id, id);
    return id;
  };
  const ctx = { channelId: hChannel.id, messageIds: [hMsg.id] };

  const empty = await threads(dave.token);
  check('처음엔 빈 목록 · 커서 null', empty.status === 200 && empty.json?.items?.length === 0 && empty.json.nextCursor === null, JSON.stringify(empty.json));

  // 사슬 A: 질문 → 이어 묻기
  const aRoot = await hDone(dave.token, await hAsk(dave.token, { instruction: `${stamp} 기록 A`, context: ctx }));
  const aFollow = await hDone(dave.token, await hAsk(dave.token, { instruction: '기록 A 이어서', parentRunId: aRoot }));
  const aTip = (await api('GET', `/spaces/${hs.id}/ai/runs/${aFollow}`, { token: dave.token })).json;
  const l1 = (await threads(dave.token)).json;
  const a = l1?.items?.[0];
  check(
    '★ 사슬이 한 줄 · 문답 2 · 질문 · 근거',
    l1?.items?.length === 1 && a?.rootRunId === aRoot && a.turnCount === 2 &&
      a.question === `${stamp} 기록 A` && a.preset === null && a.kind === 'ask' &&
      a.context?.channelId === hChannel.id && a.context.messageCount === 1 && a.context.repoId === null,
    JSON.stringify(l1),
  );
  check(
    '미리보기는 끝 답 원문의 앞부분',
    typeof aTip?.result?.markdown === 'string' && a?.preview?.length > 0 && aTip.result.markdown.startsWith(a.preview),
    JSON.stringify({ preview: a?.preview }),
  );

  const t1 = await thread(dave.token, aRoot);
  check(
    '★ 사슬 열기 — 뿌리부터 두 문답 · 질문 · 부모',
    t1.status === 200 && t1.json?.turns?.length === 2 &&
      t1.json.turns[0].runId === aRoot && t1.json.turns[0].instruction === `${stamp} 기록 A` &&
      t1.json.turns[1].runId === aFollow && t1.json.turns[1].instruction === '기록 A 이어서' &&
      t1.json.turns[1].parentRunId === aRoot && t1.json.turns[1].state === 'done' &&
      t1.json.context?.messageIds?.[0] === hMsg.id,
    JSON.stringify(t1.json),
  );

  // 가지: 같은 부모(뿌리)에 다른 질문 → 늦은 쪽이 끝
  const aBranch = await hDone(dave.token, await hAsk(dave.token, { instruction: '기록 A 가지', parentRunId: aRoot }));
  const t2 = (await thread(dave.token, aRoot)).json;
  check(
    '★ 가지가 생기면 가장 늦게 끝난 답이 끝이다',
    t2?.turns?.length === 2 && t2.turns[1].runId === aBranch,
    JSON.stringify(t2?.turns?.map((t) => t.runId)),
  );

  // 사슬 B(프리셋 요약) — 나중에 끝났으니 위
  const bRoot = await hDone(dave.token, await hAsk(dave.token, { preset: 'summary', context: ctx }));

  check(
    '★ 나중에 답을 받은 사슬이 위 · 프리셋은 question null',
    l2?.items?.length === 2 && l2.items[0].rootRunId === bRoot && l2.items[0].question === null &&

  check(
    '★ 다시 이어 물은 사슬이 맨 위로 · 문답 3',

  );

  const p2 = p1?.nextCursor ? (await threads(dave.token, `?limit=1&cursor=${p1.nextCursor}`)).json : null;
  check(
    '★ limit=1 커서로 둘째 페이지 · 끝은 null',
    p1?.items?.length === 1 && p1.items[0].rootRunId === aRoot && p1.nextCursor === aRoot &&
      p2?.items?.length === 1 && p2.items[0].rootRunId === bRoot && p2.nextCursor === null,
    JSON.stringify({ p1, p2 }),
  );

  // 실패한 뿌리는 목록에 없고 열면 404

    failedRow?.json?.state === 'failed' && l4?.items?.length === 2 && !l4.items.some((i) => i.rootRunId === failedId),

  );
  check('실패한 뿌리를 열면 404', (await thread(dave.token, failedId)).status === 404);

  const erinList = (await threads(erin.token)).json;
  check('★ 다른 사용자의 목록에 없다', Array.isArray(erinList?.items) && erinList.items.length === 0, JSON.stringify(erinList));
  check('★ 다른 사용자가 열면 404', (await thread(erin.token, aRoot)).status === 404);
  check('뿌리가 아닌 id 로 열면 404', (await thread(dave.token, aFollow)).status === 404);
  const daveOther = (await api('POST', '/spaces', { token: dave.token, body: { name: `ai hist2 ${stamp}` } })).json;
  check('다른 스페이스 경로로 열면 404', (await thread(dave.token, aRoot, daveOther.id)).status === 404);
  check('없는 id 는 404', (await thread(dave.token, UNKNOWN_UUID)).status === 404);

    token: dave.token, body: { name: `hist-private-${stamp}`, isPrivate: true },
```

```ts
import { Injectable, NotFoundException } from '@nestjs/common';
import { Prisma, SpaceMember } from '@prisma/client';
import { PrismaService } from '../prisma/prisma.service';
import { ChannelsService } from '../channels/channels.service';
import { PaginationDto } from '../common/dto/pagination.dto';
import { MAX_THREAD_TURNS } from './prompts/follow-up';
import { RUN_VIEW_SELECT, toRunView } from './run-view';
import {
  listContextOf,
  previewOf,
  rootQuestionOf,
  threadContextOf,
} from './ai-history';
import type { StoredAskInput } from './ai.service';

/** 목록 기본 크기. 패널 안이라 공용 기본(30)보다 작다(19 설계 D13). */
export const THREAD_PAGE = 20;

interface TipRow {
  rootId: string;
  tipId: string;
  path: string[];
  at: Date;
}

/**
 * AI 기록(19). **읽기만 한다** — 적재 · 워커와 의존을 나누려고 `AiService` 와 떼었다.
 * 스키마를 바꾸지 않고 `parent_run_id` 를 재귀 CTE 로 따라 내려간다(설계 D3).
 */
@Injectable()
export class AiHistoryService {
  constructor(
    private readonly prisma: PrismaService,
    private readonly channels: ChannelsService,
  ) {}

  async list(member: SpaceMember, query: PaginationDto) {
    // PaginationDto 의 기본(30)은 class 필드 초기값이라 쿼리에 없을 때만 남는다 —
    // 이 경로는 20 을 기본으로 둔다.
    const limit = query.limit === undefined || query.limit === 30 ? THREAD_PAGE : query.limit;
    const tips = await this.tips(member, { cursor: query.cursor ?? null, limit: limit + 1 });
    const page = tips.slice(0, limit);
    const nextCursor = tips.length > limit ? page[page.length - 1].rootId : null;

    const ids = [...new Set(page.flatMap((t) => [t.rootId, t.tipId]))];
    const rows = await this.prisma.aiRun.findMany({
      where: { id: { in: ids }, spaceId: member.spaceId, userId: member.userId },
      select: { id: true, kind: true, input: true, result: true },
    });
    const byId = new Map(rows.map((r) => [r.id, r]));

    const items = page.flatMap((t) => {
      const root = byId.get(t.rootId);
      const tip = byId.get(t.tipId);
      if (!root || !tip) return [];
      const input = root.input as StoredAskInput;
      return [
        {
          rootRunId: root.id,
          kind: root.kind,
          ...rootQuestionOf(input),
          turnCount: t.path.length,
          lastAt: t.at,
          preview: previewOf(tip.kind, tip.result),
          context: listContextOf(input),
        },
      ];
    });
    return { items, nextCursor };
  }

  async thread(member: SpaceMember, rootRunId: string) {
    const [tip] = await this.tips(member, { rootId: rootRunId, cursor: null, limit: 1 });
    if (!tip) throw new NotFoundException('대화를 찾을 수 없습니다');

    const rows = await this.prisma.aiRun.findMany({
      where: { id: { in: tip.path }, spaceId: member.spaceId, userId: member.userId },
      select: { ...RUN_VIEW_SELECT, input: true },
    });
    const byId = new Map(rows.map((r) => [r.id, r]));
    const chain = tip.path.map((id) => byId.get(id)).filter((r) => r !== undefined);
    // 경로 위 행이 그사이 지워졌으면(부모 cascade) 사슬을 다시 만들 수 없다.
    if (chain.length !== tip.path.length) throw new NotFoundException('대화를 찾을 수 없습니다');

    const rootInput = chain[0].input as StoredAskInput;
    return {
      rootRunId,
      context: threadContextOf(rootInput),
      turns: chain.map((row, i) => {
        const { input, ...view } = row;
        const stored = input as StoredAskInput;
        return {
          ...toRunView(view),
          // 뿌리는 지시문 또는 프리셋, 뒤 문답은 지시문뿐이다(13-3 D2).
          ...(i === 0
            ? { instruction: rootQuestionOf(stored).question, preset: rootQuestionOf(stored).preset }
            : { instruction: stored.instruction ?? null, preset: null }),
        };
      }),
    };
  }

  /**
   * 사슬마다 끝(가장 늦게 끝난 done, 설계 D4)과 뿌리→끝 경로. **본인 것 · 이 스페이스 ·
   * 지금 볼 수 있는 채널의 것만**(D6 · D7). 정렬은 끝 시각 내림차순(D5).
   *
   * `now()` 를 쓰지 않는다(시각 비교가 없다). id 를 `::uuid` 로 캐스팅하지 않는다 — `text` 다.
   */
  private async tips(
    member: SpaceMember,
    opts: { rootId?: string; cursor: string | null; limit: number },
  ): Promise<TipRow[]> {
    const viewable = await this.channels.viewableChannelIds(member);
    const onlyRoot = opts.rootId ? Prisma.sql`AND id = ${opts.rootId}` : Prisma.empty;
    const afterCursor =
      opts.cursor !== null
        ? Prisma.sql`WHERE (at, root_id) < (SELECT at, root_id FROM tips WHERE root_id = ${opts.cursor})`
        : Prisma.empty;

    return this.prisma.$queryRaw<TipRow[]>`
      WITH RECURSIVE roots AS (
        SELECT id FROM ai_runs
        WHERE space_id = ${member.spaceId} AND user_id = ${member.userId}
          AND parent_run_id IS NULL AND state = 'done'
          AND (input->>'channelId' IS NULL OR input->>'channelId' = ANY(${viewable}::text[]))
          ${onlyRoot}
      ), t AS (
        SELECT r.id, r.id AS root_id, ARRAY[r.id] AS path,
               coalesce(r.finished_at, r.created_at) AS at
        FROM ai_runs r JOIN roots USING (id)
        UNION ALL
        SELECT c.id, t.root_id, t.path || c.id, coalesce(c.finished_at, c.created_at)
        FROM ai_runs c JOIN t ON c.parent_run_id = t.id
        WHERE c.state = 'done' AND c.space_id = ${member.spaceId}
          AND cardinality(t.path) < ${MAX_THREAD_TURNS}
      ), tips AS (
        SELECT DISTINCT ON (root_id) root_id, id AS tip_id, path, at
        FROM t ORDER BY root_id, at DESC, id DESC
      )
      SELECT root_id AS "rootId", tip_id AS "tipId", path, at FROM tips
      ${afterCursor}
      ORDER BY at DESC, root_id DESC
      LIMIT ${opts.limit}
    `;
  }
}
```

```dart
    await tester.tap(find.byWidgetPredicate((w) => w is NxIconButton && w.label == 'AI 에게 묻기'));
    await tester.pumpUntil(find.widgetWithText(NxButton, '지난 대화'));
    await tester.typeInto(find.widgetWithText(NxField, '무엇이든 물어보세요'), firstQ);
    await tester.pump();
    await tester.tap(find.widgetWithText(NxButton, '보내기'));
    await tester.pumpUntil(find.widgetWithText(NxField, '이어서 묻기'));
    await tester.typeInto(find.widgetWithText(NxField, '이어서 묻기'), 'flow follow');
    await tester.pump();
    await tester.tap(find.widgetWithText(NxButton, '보내기'));
    await tester.pumpUntil(find.text('flow follow'));
    await tester.pumpUntil(find.widgetWithText(NxField, '이어서 묻기'));
    await tester.tap(find.byWidgetPredicate((w) => w is NxIconButton && w.label == '닫기'));
    await tester.pumpUntilGone(find.widgetWithText(NxField, '이어서 묻기'));

    await tester.tap(find.byWidgetPredicate((w) => w is NxIconButton && w.label == 'AI 에게 묻기'));
    await tester.pumpUntil(find.widgetWithText(NxButton, '지난 대화'));
    await tester.tap(find.widgetWithText(NxButton, '지난 대화'));
    await tester.pumpUntil(find.text(firstQ));
    await tester.tap(find.text(firstQ));
    await tester.pumpUntil(find.text('flow follow'));
    expect(find.text(firstQ), findsOneWidget);
    await tester.tap(find.byWidgetPredicate((w) => w is NxIconButton && w.label == '닫기'));
```

`pumpUntilGone` 같은 헬퍼가 없으면 파일 끝의 `WidgetTester` 확장에 있는 것을 확인해 쓴다(없으면 `pumpUntilTrue(() async => find…evaluate().isEmpty, …)`). 테스트 이름에 「→ AI 기록」을 더한다.
