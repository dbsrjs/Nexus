# 16-1 스페이스 수준 멤버 관리 — 구현 계획

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 앱 안에서 스페이스를 만들고, 초대 코드를 만들어 건네고, 받은 코드로 참여하고, 멤버의 역할을 바꾸거나 내보내고, 스스로 나갈 수 있게 한다.

**Architecture:** 서버는 기존 `spaces/` 모듈에 초대 목록 · 취소 · 나가기 API 와 멤버 이벤트(`member:*` · `space:removed`)를 더하고, 내보낸 사용자의 소켓을 서버가 직접 룸에서 뺀다. 앱은 셸 밖 덮어 여는 **스페이스 설정 창**(`/s/:spaceId/settings/:section`)을 14단계 `SettingsFrame` 위에 세우고, 채널 판 머리 줄에 스페이스 메뉴를 단다. 내보내지면 그 스페이스의 drift 캐시와 전송 큐를 지운다.

**Tech Stack:** NestJS · Prisma · Socket.IO(서버) / Flutter · Riverpod 3 · go_router · drift · 자체 UI `ui/`(앱)

**Spec:** [docs/superpowers/specs/2026-10-04-16-멤버-권한-design.md](../specs/2026-10-04-16-멤버-권한-design.md) — §0 D1~D14 · §1 16-1 · §3 · §5

## Global Constraints

- 코드 주석 · 커밋 메시지 · 문서는 **한국어**. 커밋 제목은 **명사로 끝낸다**(`추가` · `수정` · `삭제`) — 「~한다」 금지. **`Co-Authored-By` 를 넣지 않는다**
- 테넌트 격리: `:spaceId` 라우트에는 `SpaceGuard`. 볼 수 없으면 404
- 읽기 라우트(`GET .../members`)에 `@MinRole` 을 걸지 않는다
- 서버 오류 문구를 앱 화면에 쓰지 않는다 — `ApiFailure` 로 받아 앱 문구를 쓴다
- 앱 화면은 `ui/` 만 쓴다 — `material` · `cupertino` import 금지(`test/no_platform_ui_test.dart`)
- 색 · 글자 · 간격은 `NxTheme` 에서만 꺼낸다. 목록 줄 앞 장식 아이콘을 두지 않는다
- 반응형 폭 분기는 `features/shell/app_shell.dart` 에서만
- 모델(freezed)을 고치면 `dart run build_runner build`, 생성물(`.freezed.dart` · `.g.dart`)도 커밋
- 드리프트 캐시 테이블을 고치면 `schemaVersion` 을 올린다 — **이 계획은 테이블을 고치지 않는다**(지우기만 한다)
- 서버 변경을 「됐다」고 하려면 실서버 · 실DB 계약 검증(`check:members`)을 통과해야 한다(CLAUDE.md §6)

```ts
/**
 * 초대가 아직 쓸 수 있는가 — 만료 전이고 사용 한도가 남았다(16단계 설계 D9).
 *
 * 수락(`acceptInvite`)은 만료와 한도를 따로 검사해 서로 다른 순간에 판정한다(한도는
 * 트랜잭션 안의 조건부 갱신). 이 함수는 **목록에 보일지**만 정한다.
 */
export function isInviteUsable(
  invite: { expiresAt: Date | null; maxUses: number | null; useCount: number },
  now: Date,
): boolean {
  if (invite.expiresAt && invite.expiresAt.getTime() <= now.getTime()) return false;
  if (invite.maxUses !== null && invite.useCount >= invite.maxUses) return false;
  return true;
}
```

`spaces.service.ts` — `createInvite` 아래에 더한다(`import { isInviteUsable } from './invite-usable';`):

```ts
  /**
   * GET /api/spaces/:spaceId/invites (admin+) — **아직 쓸 수 있는 것만**(설계 D9).
   * 지난 행은 지우지 않는다 — 누가 언제 만들었는지는 남는다.
   */
  async listInvites(spaceId: string) {
    const invites = await this.prisma.invite.findMany({
      where: { spaceId },
      orderBy: { createdAt: 'desc' },
      include: { createdBy: { select: { id: true, name: true } } },
    });
    const now = new Date();
    return invites.filter((invite) => isInviteUsable(invite, now));
  }

  /**
   * DELETE /api/spaces/:spaceId/invites/:inviteId (admin+) — 행을 지운다(설계 D8).
   * 초대는 사용자가 쓴 글이 아니다. 다른 스페이스의 id 는 404.
   */
  async revokeInvite(spaceId: string, inviteId: string): Promise<void> {
    const { count } = await this.prisma.invite.deleteMany({
      where: { id: inviteId, spaceId },
    });
    if (count === 0) {
      throw new NotFoundException('초대를 찾을 수 없습니다');
    }
  }
```

5. `requireMember` 위에 새 메서드 셋:

```ts
  /**
   * POST /api/spaces/:spaceId/leave — 스스로 나간다(설계 D11).
   * owner 는 403 — 소유권 이전이 없어 나가면 주인 없는 스페이스가 된다.
   */
  async leave(member: SpaceMember): Promise<void> {
    if (member.role === SpaceRole.owner) {
      throw new ForbiddenException('owner 는 스페이스를 나갈 수 없습니다');
    }
    await this.dropMembership(member.spaceId, member.userId);
    this.notifyRemoved(member.spaceId, member.userId);
  }

  /**
   * 스페이스 멤버십과 그 스페이스의 채널 멤버십을 한 트랜잭션으로 지운다.
   * 채널 멤버십을 남기면 나간 사람이 읽음 마커 · 멘션 계산에 끼어든다.
   */
  private async dropMembership(spaceId: string, userId: string): Promise<void> {
    await this.prisma.$transaction([
      this.prisma.channelMember.deleteMany({
        where: { userId, channel: { spaceId } },
      }),
      this.prisma.spaceMember.delete({
        where: { spaceId_userId: { spaceId, userId } },
      }),
    ]);
  }

  /**
   * 내보내지거나 나간 뒤의 실시간 처리(설계 D12 · D13 · D13a).
   *
   * **룸에서 먼저 뺀다** — 그 뒤로 이 스페이스에 쏘는 것은 그 사람에게 닿지 않는다.
   * 채널 id 는 그 스페이스의 채널 전부다(볼 수 있던 것만 고를 필요가 없다 — 없는
   * 룸에서 빼는 것은 아무 일도 하지 않는다).
   */
  private notifyRemoved(spaceId: string, userId: string): void {
    void this.prisma.channel
      .findMany({ where: { spaceId }, select: { id: true } })
      .then((channels) => {
        this.realtime.evict(userId, [
          room.space(spaceId),
          ...channels.map((c) => room.channel(c.id)),
        ]);
        this.realtime.toUser(userId, 'space:removed', { spaceId });
        this.realtime.toUser(userId, 'rooms:invalidate', { reason: 'member.left' });
        this.realtime.toSpace(spaceId, 'member:left', { spaceId, userId });
      });
  }
```

> `notifyRemoved` 를 `void ... .then` 으로 둔 이유: 응답을 실시간 처리 뒤로 늦추지 않는다. 다만 **채널 조회가 실패하면 룸에서 빠지지 않는다** — 실패를 삼키지 않게 `.catch((err) => this.logger.error(...))` 를 붙인다. 서비스에 `private readonly logger = new Logger(SpacesService.name);`(`Logger` 를 `@nestjs/common` 에서 import)를 둔다.

```dart
/// 붙여넣은 글에서 초대 코드를 읽는다(16단계 설계 D2).
///
/// 코드는 서버가 만든 **영소문자 · 숫자 12자**다(`generateInviteCode`). 메신저로 받은
/// 문장을 통째로 붙여넣어도 되게, 영숫자가 아닌 글자로 자른 조각 중 **마지막 12자**를 쓴다.
/// 딥링크는 «마지막» 단계라 여기서는 주소를 해석하지 않는다.
String? parseInviteCode(String input) {
  final tokens = input
      .toLowerCase()
      .split(RegExp(r'[^a-z0-9]+'))
      .where((t) => t.length == 12);
  return tokens.isEmpty ? null : tokens.last;
}
```

```dart
class InvitesApi {
  InvitesApi(this._client);

  final ApiClient _client;

  Future<Invite> create(
    String spaceId, {
    required SpaceRole role,
    int? expiresInHours,
    int? maxUses,
  }) => _guard(() async {
        final res = await _client.dio.post<Map<String, dynamic>>(
          '/spaces/$spaceId/invites',
          data: {
            'role': role.wire,
            'expiresInHours': ?expiresInHours,
            'maxUses': ?maxUses,
          },
        );
        return Invite.fromJson(res.data!);
      });

  Future<List<Invite>> list(String spaceId) => _guard(() async {
        final res = await _client.dio.get<List<dynamic>>('/spaces/$spaceId/invites');
        return (res.data ?? const [])
            .cast<Map<String, dynamic>>()
            .map(Invite.fromJson)
            .toList(growable: false);
      });

  Future<void> revoke(String spaceId, String inviteId) =>
      _guard(() => _client.dio.delete<void>('/spaces/$spaceId/invites/$inviteId'));

  /// 응답의 스페이스에는 내 역할이 없다 — 초대의 역할을 알 수 없어 목록을 다시 받아야
  /// 정확하다. 부르는 쪽은 `refreshSpaces()` 뒤에 `id` 로 들어간다.
  Future<String> accept(String code) => _guard(() async {
        final res = await _client.dio.post<Map<String, dynamic>>('/invites/$code/accept');
        return res.data!['id'] as String;
      });

  Future<T> _guard<T>(Future<T> Function() call) async {
    try {
      return await call();
    } on DioException catch (e) {
      throw ApiException(classifyDioException(e));
    }
  }
}
```

```dart
class SpaceSettingsScreen extends ConsumerWidget {
  const SpaceSettingsScreen({super.key, required this.spaceId, this.section});

  final String spaceId;
  final SpaceSettingsSection? section;

  @override
  Widget build(BuildContext context, WidgetRef ref) {
    final spaces = ref.watch(spacesProvider).value;
    final space = spaces?.where((s) => s.id == spaceId).firstOrNull;
    if (spaces != null && space == null) {
      WidgetsBinding.instance.addPostFrameCallback((_) {
        if (context.mounted) context.go('/spaces');
      });
    }
    if (space == null) return const NxPage(body: NxSkeleton(lines: 4));

    final visible = SpaceSettingsSection.visibleFor(space.role);
    final current = section == null
        ? null
        : (visible.contains(section) ? section! : visible.first);
    void close() => context.go('/s/$spaceId');

    Widget content(SpaceSettingsSection s) => switch (s) {
          SpaceSettingsSection.general => GeneralSection(space: space),
          SpaceSettingsSection.members => MembersSection(spaceId: spaceId, me: space.role),
          SpaceSettingsSection.invites => InvitesSection(spaceId: spaceId),
        };

    return CallbackShortcuts(
      bindings: {const SingleActivator(LogicalKeyboardKey.escape): close},
      child: Focus(
        autofocus: true,
        child: SettingsFrame(
          title: '스페이스 설정',
          nav: _Nav(
            title: space.name,
            sections: visible,
            selected: current,
            onSelect: (s) => context.go(spaceSettingsLocation(spaceId, s)),
          ),
          content: current == null ? null : content(current),
          fallback: content(visible.first),
          onClose: close,
          onBack: () => context.go(spaceSettingsLocation(spaceId, null)),
        ),
      ),
    );
  }
}
```

```dart
class SpaceMenu extends ConsumerWidget {

      confirmLabel: '나가기',
      danger: true,
    );
    if (!ok || !context.mounted) return;
    try {
      await ref.read(spacesApiProvider).leave(space.id);
      await ref.read(forgetSpaceProvider)(space.id);
    } on ApiException catch (e) {
      if (context.mounted) {
        NxToast.show(context, messageFor(e.failure), kind: NxToastKind.error);
      }
    }
  }
}
```
