# 15-2 화면 옮기기 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** `lib/features` · `lib/shared` 의 화면이 Material 위젯 대신 `lib/ui/` 만 쓰게 하고, 옮긴 파일을 허용 목록에서 지운다.

**Architecture:** 앱 뼈대(`MaterialApp.router`)는 15-3 까지 그대로 두고, 그 `builder` 에 `NxRoot`(NxTheme · 토스트 · 스크롤 동작)를 끼워 **옮긴 화면과 안 옮긴 화면이 한 앱에 함께 선다.** 영역마다 한 커밋 — 그 영역의 파일이 material 을 더는 import 하지 않고, 허용 목록에서 빠지고, 테스트 · `app:flow` 가 통과한 상태로 끝난다.

**Tech Stack:** Flutter widgets 층 · `lib/ui/`(15-1) · go_router · Riverpod 3 · drift

**Spec:** [docs/superpowers/specs/2026-09-27-15-자체-UI-design.md](../specs/2026-09-27-15-자체-UI-design.md) §3 · 디자인 캔버스 https://claude.ai/artifact/PUzzfyCr6b7bEA4oYqnUvJ

## Global Constraints

- 옮긴 파일은 `package:flutter/material.dart` · `cupertino.dart` 를 import 하지 않는다(`test/no_platform_ui_test.dart` 가 막는다)
- 플랫폼 패턴도 쓰지 않는다 — 손잡이 바텀시트 · NavigationBar · 햄버거 · 물결 · **목록 줄 앞 장식 아이콘** · 회전 스피너 · SnackBar
- 토큰 이름을 바꾸지 않는다. 색 · 간격 토큰을 새로 만들지 않는다
- 반응형 폭 분기는 `features/shell/app_shell.dart` 한 곳
- 서버 오류 문구를 화면에 그대로 쓰지 않는다(기존 규칙 그대로)
- 커밋 메시지 한국어 · 제목은 명사로 끝냄(`… 이관` · `… 추가` · `… 수정`) · Co-Authored-By 넣지 않음

## 스펙과 다르게 정한 것

- **공용(아바타 · 로고 · 마크다운)을 맨 뒤가 아니라 맨 앞으로.** 잎 위젯이라 어느 화면에나 들어간다 — 뒤로 두면 먼저 옮긴 화면이 안에 Material 위젯을 품은 채 남아, 그 화면의 위젯 테스트를 `WidgetsApp` 으로 띄울 수 없다
- **테마 설정 값을 자체 enum(`ThemePreference`)으로.** `ThemeMode` 는 Material 이다. `main.dart` 가 15-3 까지 `ThemeMode` 로 바꿔 넘긴다

## 바꾸는 법 (모든 Task 공통)

| Material | 자체 |
|---|---|
| `Theme.of(context)` | `NxTheme.of(context)` (`final nx = NxTheme.of(context); final c = nx.colors;`) |
| `textTheme.bodyMedium` · `bodyLarge` | `nx.text.body` |
| `textTheme.bodySmall` · `labelMedium` | `nx.text.secondary` |
| `textTheme.labelSmall` | `nx.text.meta` |
| `textTheme.titleSmall` | `nx.text.strong` |
| `textTheme.titleMedium` | `nx.text.title` |
| `textTheme.titleLarge` · `headlineSmall` | `nx.text.heading` · `nx.text.xl.copyWith(fontWeight: w600)` |
| `dividerColor` | `c.divider` |
| `colorScheme.primary` · `onPrimary` | `c.accent` · `c.onAccent` |
| `colorScheme.error` · `onError` | `c.danger` · `c.onAccent` |
| `colorScheme.surface` · `surfaceContainerHighest` | `c.bgSurface` · `c.bgElevated` |
| `scaffoldBackgroundColor` | `c.bgBase` |
| `hintColor` · `outline` | `c.textSecondary` · `c.borderStrong` |
| `Scaffold` + `AppBar` | `NxPage(header: NxHeader(...))` |
| `ListTile` | `NxRow` — **`leading` 의 장식 아이콘은 지운다**(아바타 · 상태 점만 남긴다) |
| `FilledButton` · `OutlinedButton` · `TextButton` | `NxButton(kind: primary · secondary · ghost)` |
| `IconButton` | `NxIconButton(label: …)` — 라벨은 필수(보조 기술) |
| `Icon(Icons.x)` | `NxIcon(NxIcons.x)` — 없는 아이콘은 `ui/icons.dart` 에 경로를 더한다. **장식이면 지운다** |
| `TextField` · `TextFormField` | `NxField` |
| `SnackBar` · `ScaffoldMessenger` | `NxToast.show(context, …)` |
| `CircularProgressIndicator` | 목록 · 본문은 `NxSkeleton`, 버튼 안은 `NxButton(loading: true)` |
| `showDialog` + `AlertDialog` | `NxDialog.confirm` · 입력이 있으면 `showGeneralDialog` 위에 자체 패널 |
| `showModalBottomSheet` | 데스크톱 · 모바일 모두 `NxDialog` 계열 패널(손잡이 없음) — 메시지 길게 누르기는 `NxActionCard` |
| `PopupMenuButton` | `NxMenu` |
| `Chip` · `FilterChip` · `Badge` | `NxChip` · `NxBadge` · `NxTag` |
| `Switch` · `Checkbox` · `SegmentedButton` · `DropdownButton` | `NxSwitch` · `NxCheck` · `NxSegmented` · `NxSelect` |
| `Divider` · `VerticalDivider` | `NxDivider` |
| `InkWell` · `Material` · `Card` | `NxPressable` · `Container(decoration: …)`(그림자 없음) |
| `Tooltip` | `NxTooltip` |
| `TabBar` · `NavigationBar` | `NxTabBar` |
| `SelectableText` | `Text` 를 `SelectableRegion` 없이 — 필요하면 15-3 에서 따로 정한다 |

## 테스트 호스트

`test/support/nx_host.dart` 에 `nxTestApp({required Widget home, Brightness brightness = Brightness.dark, List overrides})` —
**15-3 전까지는 `MaterialApp` + `NxRoot`**(실제 앱과 같은 짜임). 옮긴 화면의 테스트는 이것으로 띄우고, Material 타입으로
찾던 곳(`find.byType(FilledButton)` · `ListTile` · `SnackBar`)은 `Nx` 타입이나 글자로 바꾼다. 15-3 에서 이 함수 안만
`WidgetsApp` 으로 바꾼다.
